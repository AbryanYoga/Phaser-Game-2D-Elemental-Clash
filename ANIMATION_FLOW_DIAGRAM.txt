┌─────────────────────────────────────────────────────────────────────────────┐
│                          ANIMATION SPAM PREVENTION                          │
└─────────────────────────────────────────────────────────────────────────────┘

    ❌ BAD (Old System):
    ═══════════════════
    Every frame:
        this.play('run');  // Restarts animation every frame!
        this.play('run');  // Causes flickering and spam
        this.play('run');  // Animation never completes
    
    
    ✅ GOOD (New System):
    ═══════════════════
    changeAnimation(key) {
        // Check if already playing
        if (this.anims.currentAnim?.key === key) {
            return;  // Don't restart!
        }
        
        // Check if locked
        if (this.animationState.locked) {
            return;  // Don't interrupt!
        }
        
        // Safe to change
        this.play(key, true);
    }
